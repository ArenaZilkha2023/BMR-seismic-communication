# 5) METHOD NOTES / ENVIRONMENT

- Data: /Data/clicks (waveform, cols 8-30), /Data/clicks_metadata (sequence params),
  /Data/no_clicks (noise). All R6* files excluded from the four main analyses.
- Random seed 42; 70/30 stratified splits; class weights balanced; Borderline-SMOTE+ADASYN
  oversampling on waveform training (as in original pipeline).
- Waveform RF = 150 trees, full depth (the config the original randomized search selects;
  a depth-10 variant scores only 0.71, confirming full depth is the tuned model).
- Waveform SHAP per-column bars (Fig.4A): computed with the fast tree-path-dependent
  explainer on a representative RF (interventional-probability SHAP on the full-depth
  forest is computationally infeasible in this environment); the pattern - importance
  spread across the window with ~0 at the aligned/normalized peak - is what the figure shows.
- Sequence 8-seed SHAP: interventional-probability (matches the paper's method), seeds 42-49.
- Noise-only: full training data, 300-tree RF, centered 23-col window (matches original).
- Sex: waveform features, grouped split by animal (GroupShuffleSplit), permutation over all
  9 alternative animal->sex assignments; observed within null (p=0.20).

   different metrics. Verified with identical full pipeline (300 trees, full data):

   RAW accuracy (inflated by the majority class R4). Like-for-like, noise balanced
   accuracy is 61.9% ~ unchanged from 61.2%. Document corrected to 61.9%.
   (Under identical settings, removing R6 raises balanced acc only ~58.6% -> 61.9%.)
